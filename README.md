# Fabric Metadata Framework

Marco de trabajo para la aceleración de proyectos de analítica de datos en Microsoft Fabric basado en el uso de metadatos. Permite la ingesta, consolidación, refinamiento y transformación de datos desde múltiples orígenes, facilitando la estandarización y automatización de procesos combinando el uso de dichos metadatos y artefactos modulares.

## 📦 Contenidos

### 📁 [docs](/doc/)

Este directorio contiene la documentación de la solución en formato ```Markdown```.

### 📁 [samples](/samples/)

Conjunto de ficheros de ejemplo que sirven como referencia para hacer funcionar el marco de trabajo correctamente.

### 📁 [scripts](/scripts/)

Colección de scripts para distintas finalidades (otorgar accesos, promoción entre entornos, etc.)

### 📁 [sql](/sql/)

Proyecto de base de datos para albergar los metadatos que emplea el proyecto.

### 📁 [src](/src/)
Código fuente de la solución.
